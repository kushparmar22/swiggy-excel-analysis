# 🍔 Swiggy Data Analysis Dashboard (Excel Project)

## 📌 Overview

This project presents a comprehensive data analysis of Swiggy food delivery data using **Microsoft Excel**. The goal is to extract meaningful insights and visualize them through an interactive dashboard.

The project demonstrates strong skills in **data cleaning, analysis, and dashboard creation using Excel tools**.

---

## 🎯 Objectives

* Analyze restaurant data and customer preferences
* Identify popular cuisines and top-performing restaurants
* Understand pricing and rating trends
* Build an interactive dashboard for easy data exploration

---

## 🛠️ Tools & Techniques Used

* **Microsoft Excel**

  * Data Cleaning
  * Pivot Tables
  * Pivot Charts
  * Slicers
  * Conditional Formatting
  * Dashboard Design
